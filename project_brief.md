Create a detailed PROJECT_BRIEF.md file for a premium web project called “Build Bharat Synergy Partners”.

PROJECT CONTEXT:

Build Bharat Synergy Partners is a parent-company ecosystem that brings together four independent companies operating across different industries:

1. Solar / Renewable Energy
2. Loans / Financial Services
3. Real Estate
4. Education / EdTech

The website is not meant to be a traditional corporate website or a simple company directory.

It should function as an interactive digital gateway into the Build Bharat ecosystem.

The main idea is:

                 BUILD BHARAT
                      │
       ┌──────────────┼──────────────┐
       │              │              │
    ☀️ SOLAR       💰 LOANS       🏢 REAL ESTATE      🎓 EDUCATION

The main purpose of the website is to help visitors quickly discover which company or business within the ecosystem is relevant to their needs.

CORE USER EXPERIENCE:

The landing page should immediately ask:

“What are you looking for?”

The user should be able to:
- Type what they need in natural language
- Explore predefined categories
- Select one of the four business pillars
- Receive the relevant company or business pathway
- Navigate to the individual company’s official website

Example user queries:

“I want to install solar panels”
→ Solar / Renewable Energy

“I need a business loan”
→ Loans / Financial Services

“I want to buy a house”
→ Real Estate

“I want to learn coding”
→ Education / EdTech

The experience should feel intuitive, intelligent, premium, and human.

PROJECT GOAL:

Create a modern ecosystem website that makes Build Bharat Synergy Partners feel larger than a traditional parent company.

The website should communicate:

“Different businesses. Different expertise. One connected ecosystem.”

DESIGN DIRECTION:

The website should feel:

- Premium
- Modern
- Minimal
- Intelligent
- Trustworthy
- Corporate
- Futuristic

- High-end

Avoid:
- Generic corporate templates
- Boring business layouts
- Excessive text

- Excessive gradients
- Unnecessary visual clutter

The design should prioritize:
- Strong typography
- Clear hierarchy
- Large visual sections

- Purposeful animation
- Elegant spacing
- High-quality imagery
- Strong brand presence
